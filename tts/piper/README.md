# Piper offline TTS

1. Run **`setup.bat`** — downloads `piper.exe` for Windows.
2. Place `.onnx` voice models here (you already have `en_US-lessac-medium.onnx`).
3. In the app: **Settings → Audio → TTS mode → Offline** → **Offline voice → Neural (Piper CLI)**.

Models also work from `%USERPROFILE%\.ai_reading_studio\piper_models\`.
